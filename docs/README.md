# dsh-web-relay 文档

`dsh-web-relay` 是一个 DSH 插件包：让远程设备（手机、平板、另一台电脑）经过认证后，直接使用你机器上运行的 `dsh web`。不需要 VPN，也不需要在内网做端口映射。

这套文档讲的是**部署、配置与维护**。安装与日常使用见仓库根目录的 [README](../README.md)。

## 术语

| 术语 | 含义 |
| --- | --- |
| 中继主机 | 有公网地址、承载唯一入口的那台机器（一般是一台 VPS） |
| 内网主机 | 运行 `dsh web` 的机器，可以没有公网地址 |
| 权威 | 浏览器地址栏里那一段 `host[:port]`，例如 `203.0.113.7:8443` |
| 网关口令 | 你在部署时自己设定的口令，浏览器进入时输入，中继用它做第一道认证 |
| 访问地址 | `https://<权威>/`；不含任何秘密，可以收藏 |
| 换票点 | 插件在内部用一次令牌交换把"已过网关口令"换成 DSH 会话，用户看不到它 |
| 引导 | 插件用管理账号在中继上自动完成的一次配置动作；每次部署都会完整重跑一遍 |
